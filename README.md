# PHSG Präsentationen

Reveal.js statt Powerpoint

## Zweck und Kontext

Mit diesem Tool erstellst du auf Basis von reveal.js eigene Online-Präsentationen im Textformat anstatt
diese mühselig in Powerpoint zusammenzuklicken.

Features:
- Datum deiner Veranstaltung passt du einmal an und nicht in jeder einzelnen Präsentation
- Du kannst einzelne Folien in mehreren Präsentationen einsetzen
- Kleine Tools wie einen Timer kannst du direkt in der Präsentation einbauen

## Setup

Was braucht es, um damit zu arbeiten?

    git clone https://github.com/PHSG-IDIB/Tool-presentations.git

Erstelle nun den Ordner `/content` und baue deine eigenen Präsentationen ganz nach den Beispielen unter
`/content-example`.
